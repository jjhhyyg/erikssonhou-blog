## 一、核心概念

### 1.1 破坏性 vs 非破坏性操作

- **非破坏性操作**：Modifier 应用前的状态，可随时调整参数（如 Subdivision Surface、Solidify）
- **破坏性操作**：Apply Modifier 后，几何体被永久修改，无法恢复到 Modifier 状态
- **操作时机**：添加 Modifier → 使用 Loop Cut/Extrude/Inset 等工具塑形 → 确认无误后统一 Apply

## 二、关键快捷键与操作

### 2.1 视图与场景管理

| 快捷键 | 功能 | 应用场景 |
|--------|------|----------|
| **Shift+A** | 添加 Mesh | 创建基础几何体（Cube、Cylinder 等） |
| **Z** | 切换着色模式 | 实体/线框/材质预览，便于观察结构 |
| **~** (波浪号) | View 菜单 | 快速聚焦选中物体（Frame Selected）、调整视角 |

**技巧**：按 **~** 后选择 Frame Selected 可自动居中显示当前选中物体

### 2.2 选择工具

| 快捷键 | 功能 | 应用场景 |
|--------|------|----------|
| **Option/Alt + 左键** | 循环选择边/面 | 快速选中一圈边（Edge Loop）或面循环 |

**技巧**：在圆柱体侧面使用可快速选中水平或垂直的整圈边

### 2.3 形状控制（可按 X/Y/Z 限制轴向）

| 快捷键 | 功能 | 应用场景 |
|--------|------|----------|
| **G** (Grab) | 移动选中元素 | 调整位置、改变延伸方向 |
| **G + G** | 边缘滑动模式 | 沿边缘方向移动，保持拓扑结构 |
| **S** (Scale) | 缩放选中元素 | 调整大小、控制开口直径 |
| **R** (Rotate) | 旋转选中元素 | 调整朝向、旋转延伸面 |
| **R + Cmd/Ctrl** | 吸附旋转 | 旋转到固定角度（0°、15°、45°、90°等） |

**技巧**：

- 执行 G/S/R 后立即按 X/Y/Z 键可锁定单轴操作
- **G + G** 特别适合调整 Loop Cut 添加的边的位置，不会破坏模型形状
- 旋转时按住 **Cmd/Ctrl** 实现角度吸附，确保精确对齐

### 2.4 几何编辑

| 快捷键 | 功能 | 应用场景 |
|--------|------|----------|
| **Cmd+R** (Loop Cut) | 添加循环边 | **核心操作**：细化模型、控制 Subdivision 后的形状流动 |
| **E** (Extrude) | 沿法线方向延伸 | 创建杯柄、拉伸形状 |
| **I** (Inset) | 内缩面创建内圈 | 创建平滑平面、控制边缘连接关系 |
| **F** (Fill) | 填充面 | 连接顶点成面、封闭开口 |
| **X** (Delete) | 删除菜单 | 删除接触面、清理多余几何体 |

### 2.5 高级建模技巧

- **延伸杯柄的两种方法**：
  1. 渐进式：`E 延伸 → G 移动 → R 旋转面` （适合精细控制）
  2. 快速式：`Cmd + 右键点击目标位置` （自动生成路径）
  
- **桥接循环边**：选中两个边循环 → 右键 → Bridge Edge Loops  
  *注意*：桥接前需删除接触面，避免内部重叠几何体

## 三、标准工作流程

### 3.1 建立基础形状

1. **Shift+A** 创建 Cylinder（圆柱体）作为杯身

### 3.2 添加 Modifiers（非破坏性阶段）

1. 添加 **Solidify Modifier**（Generate → Solidify）
   - 调整 Thickness 参数控制壁厚
2. 添加 **Subdivision Surface Modifier**（细分曲面）
   - 提高模型精度和平滑度
3. 按 **Z** 切换到线框模式查看细分效果

### 3.3 塑形阶段（Modifier 未 Apply）

1. **Loop Cut（Cmd+R）**：添加控制边
   - 滚轮控制添加数量
   - **G + G** 滑动边缘调整位置，保持形状流动
2. **Option/Alt + 左键**：快速选中边循环
3. **Inset (I)**：创建内圈控制边缘过渡
4. **按 ~** → Frame Selected 聚焦编辑区域

### 3.4 创建杯柄

1. 选中侧面 → **E** 延伸 → **G** 调整位置
2. 配合 **S**（缩放）和 **R + Cmd/Ctrl**（精确旋转）塑造手柄形状
3. 末端与杯身桥接：
   - 删除接触面（X）
   - **Option/Alt + 左键** 选中两个边循环 → Bridge Edge Loops

### 3.5 最终确认（破坏性阶段）

1. 确认所有形状调整完毕
2. 在 Object Mode 下对所有 Modifier 执行 **Apply**
3. Apply 后可进入 Edit Mode 编辑内部细节

## 四、实操要点

✅ **Shift+A 快速创建**：避免在菜单中反复查找  
✅ **先 Solidify 再 Subdivision**：确保壁厚后再细分，避免后期调整困难  
✅ **Modifier 阶段充分塑形**：Apply 前完成主要形状调整  
✅ **Option/Alt + 左键**：高效选择边循环，配合 Bridge 等操作  
✅ **G + G 边缘滑动**：调整 Loop Cut 位置的最佳方式，保持拓扑完整  
✅ **Z 键切换视图**：线框模式便于检查拓扑结构，实体模式用于最终效果  
✅ **~ 键聚焦物体**：复杂场景中快速定位编辑对象  
✅ **Cmd/Ctrl 吸附旋转**：创建对称结构或精确角度时必用  
✅ **Loop Cut 是关键**：决定 Subdivision 后形状是否自然  
✅ **轴向限制**：G/S/R 后按 X/Y/Z 提高操作精度  
✅ **最后 Apply**：确认无误后再执行破坏性操作
